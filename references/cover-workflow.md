# 封面：先确定文字，再出三版，再选择合成

默认参考图为 `assets/covers/style-reference.png`：匿名雕塑示意的青绿笔触、浅底大字、黑金重点三栏。它由本技能作者为分发新生成，不含任何用户视频帧、身份或工程。参考只限定配色/文字层级/留白，示意雕塑不是学员视频人物，不准带到正式封面。

## 文字确认

从当前成片提两三个简短封面文案，保留原话条件/否定和概率，不增添资历、效果或保证。询问用户选哪组；明确给定封面文字即视为确认。**没有确定文字不能调用生成命令。** 用户确认后自动开始三版制作，不再让其重复选风格、字体或模型。

有原生ImageGen时先按实际工具要求说明用量；不要把无需额外API Key说成免费。默认调用三次、一张一个版本，不能捏造n/count参数。若工具要求额外授权，遵守宿主提示；若用户不想生图消耗，可直接内置版式制作三版，并明确称“排版方案”。

```text
python "<技能目录>/scripts/sayframe.py" cover-prepare --project "<工程>" --title "<已确定主标题>" --subtitle "<已确定副标题>" --confirmed
```

prepare要求当前剪辑已真实生成，自动按**当前成片的编译映射找回对应的原片帧**，避免把后加字幕/标题烧进封面；按清晰度/曝光选帧，返回工程内request.json。不会从未选的原片片段借人脸。原视频本身若已有字幕，不承诺自动消除。算法没有保证选中最佳表情，需要时用户可要求换一轮帧；未实现任意换帧入口时如实说明，不手改frame文件。

## 自动制作三个版本

1. 读取request.json。每项prompt已绑定同一张默认风格参照，按本会话ImageGen实际schema逐次提交；当前核验参数为prompt、image1、size、quality、output_dir。输出只做**无人物、无文字装饰背景**。真人使用学生自己的视频原帧，标题由本机字体精确排，不让生成模型改脸或写错字。
2. 记录实际输出的本地图片路径，不保存账户令牌或带认证的下载URL。写背景映射JSON：`{"teal":"<第一张本地图片>","ivory":"<第二张本地图片>","ink":"<第三张本地图片>"}`。只认真实文件，不捏造成功。生图提交后结果未知不要重复付费提交；先查询已有任务或保留失败说明。
3. 三图完成后，调用：

```text
python "<技能目录>/scripts/sayframe.py" cover-generate --project "<工程>" --request "<request.json>" --backgrounds "<背景映射.json>"
```

无原生生图能力/不使用生成式背景时，省略--backgrounds即可按同一参照的内置版式生成三张。它仍会生成实际JPG候选，不能把它称为AI生图。不同模式都不需要作者API Key或服务器。

## 用户选版与最终合成

用WorkBuddy图片展示能力把三个**实际候选图**并排展示，或打开工作台“封面”区，等待用户选第一/第二/第三版。生成版本不会自动替用户选定。选择后：

```text
python "<技能目录>/scripts/sayframe.py" cover-select --project "<工程>" --candidate teal --revision "<最新read的revision>"
python "<技能目录>/scripts/sayframe.py" export --project "<工程>"
```

候选ID顺序为teal/ivory/ink，用户说“第二版”就选ivory。选择也支持撤销重做。视频内容/设置改变后旧封面需重新确认，不偷偷沿用旧主题。

封面自动写进最终视频的**第一帧**，增加1/30秒静音前导，后续原声不裁断、不改序。并保留同一输出目录的cover.jpg，平台支持单独指定封面时可复用，但用户不必下载图片再手工拼进视频。成片预览/下载使用同一个合成文件。检查首帧对应选中封面、视频仍有AAC声音、原片内容与次序正常，不以候选图生成成功代替最终视频合成成功。

## 对学生隐私的界限

封面图、原帧、生成回执全部在学生自己的工程covers目录。发布技能ZIP只收录匿名默认风格参考图、代码和授权字体；不放作者或学生的视频、原帧、封面实例、工程、缓存或凭据。不得为了“给学员示例”把当前项目的真人测试图塞入包内。
